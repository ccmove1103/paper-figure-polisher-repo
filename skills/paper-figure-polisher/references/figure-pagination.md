# Figure Pagination

Use this guide when each figure should occupy its own page in a Word manuscript.

## Default Rule

Treat a figure block as:

- the figure image or chart;
- its caption;
- optional source note or abbreviation note.

Start each figure block on a new page.

## Layout Method

In Word-oriented workflows:

1. Keep figures anchored in a predictable block layout.
2. Insert a page break before each new figure block unless the figure is already the first element on a fresh page.
3. Keep the caption attached to the same block as the figure.
4. Prevent a later paragraph from flowing above the figure.

## Placement Rules

- One main figure block per page by default.
- Keep multi-panel figures together if they are a single numbered figure.
- Do not separate a figure from its caption.
- If the figure is too tall for the page, resize proportionally before moving the caption to another page.
- If the figure cannot fit legibly on one page, flag it for manual redesign rather than forcing an unreadable scale.

## Numbering Rules

- Number figures in manuscript order.
- Match every figure number against in-text citations.
- If tables and figures are both being normalized, audit both after pagination changes because renumbering one often invalidates cross-references.

## Audit Checklist

- every figure begins on a new page;
- no page contains two unrelated figure blocks;
- caption stays with the figure;
- numbering is sequential;
- in-text figure citations still match.
